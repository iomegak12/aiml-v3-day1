What is ML and Why does it matter?

Traditional Programming = Rules + Input => Output (Answers)
In ML, Input + Answers = Program which has rules learnt from the data
Data Driven Learning (Understanding and Identifying rules that make data points related)
The learnt rules are then called a MODEL
Once trained, the model can make predictions for new data it has never seen
A model can only learn patterns | relationships | how data points are correlated that are actually in the data, and it learns the mistakes and biases in that data as well
ML turns history -> decisions

Train, Validation and Test Split - Data Leakage

Training set is what the model learns from
Validation Set is used while we tune and compare models
Test set is kept locked away and used once, at the very end, to estimate real-world performance

Common split - 70:15:15 / 80:10:10

Data Leakage happens when information that would NOT be available at prediction time sneaked into the training data. It often hides in columns that are filled in after the event we’re predicting, or in pre-processing steps that look at the whole dataset before it’s split.

Scikit-Learn

It’s an open-source / community driven standard python library for classical ML, and almost every model in it follows the same pattern
